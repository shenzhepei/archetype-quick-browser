## 1. 背景

普通网页内容区尚无浏览器级右键菜单，用户无法从页面上下文执行导航、保存、查看源代码或检查元素等常用操作。

## 2. 需求与验收

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| F07-01 | 原生菜单 | 右键普通网页时显示 Electron 原生菜单，菜单不被网页内容遮挡 |
| F07-02 | 页面导航 | 菜单提供后退、前进和重新加载；无对应导航历史时禁用后退或前进 |
| F07-03 | 网页另存为 | 菜单提供网页另存为，使用系统保存对话框将页面保存为完整 HTML |
| F07-04 | 查看源代码 | HTTP/HTTPS 页面可在新标签中打开 Chromium `view-source:` 页面 |
| F07-05 | 检查元素 | 菜单可打开 Chromium DevTools 并检查右键位置对应的页面元素 |
| F07-06 | 目标一致 | 菜单命令始终作用于触发右键事件的网页标签和坐标 |
| F07-07 | 国际化 | 菜单与保存失败提示完整支持英文和简体中文 |
| F07-08 | 文件安全 | 建议文件名移除跨平台非法字符，保存取消不产生文件或错误提示 |

## 3. 非目标

- 不在本 Feature 中加入链接、图片、选中文本或输入框专属菜单命令。
- 不实现 MHTML、PDF 或截图导出。
- 不绕过网页 CSP、证书错误或 Chromium 安全限制。
