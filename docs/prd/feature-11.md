## 1. 背景

页面导航完成事件可能早于网页标题事件，导致历史记录写入 `New tab`。书签目前只有扁平列表，无法按多级文件夹组织。

## 2. 需求与验收

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| F11-01 | 过滤占位历史 | `New tab`、`新标签页`、空标题和 `about:blank` 不进入历史记录或最近历史菜单 |
| F11-02 | 标题就绪写入 | HTTP/HTTPS 页面取得有效标题后写入历史；短时间内同 URL 标题更新只更新最近记录，不重复新增 |
| F11-03 | 旧数据清理 | 启动时过滤已持久化的占位历史记录，并在后续持久化中清除 |
| F11-04 | 文件夹模型 | 书签支持可选父文件夹，文件夹支持可选父文件夹并允许多级嵌套 |
| F11-05 | 创建子文件夹 | 书签管理页可在根目录或当前文件夹下创建子文件夹 |
| F11-06 | 移动书签 | 管理页可将书签移动到根目录或任意现有文件夹 |
| F11-07 | 删除文件夹 | 用户确认后递归删除目标文件夹、子文件夹及其中书签 |
| F11-08 | 树形浏览 | 管理页侧栏和原生书签菜单按文件夹层级递归展示，点击目录查看其直接内容 |
| F11-09 | 最近书签兼容 | 主菜单继续提供最近 8 条书签，并额外展示完整文件夹树 |
| F11-10 | 数据安全 | 主进程校验父文件夹和书签 ID；无效 ID、空名称和循环数据不得破坏状态 |
| F11-11 | 国际化 | 文件夹创建、移动、删除、确认和空状态支持英文与简体中文 |

## 3. 非目标

- 不实现文件夹拖拽排序、重命名、书签导入导出或云同步。
- 不实现跨窗口实时合并编辑冲突。
