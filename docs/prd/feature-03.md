# Feature 03 标签页加载状态提示 PRD

| 字段 | 内容 |
|------|------|
| Feature ID | `feature-03` |
| 状态 | 已完成 |
| 来源 | 原需求是在标签栏下方显示窄进度条；后续调整为在每个网站标签标题前显示旋转加载图标，并将 favicon 放在加载图标内 |
| 对应详设 | [feature-03.md](../detailed-design/feature-03.md) |

## 1. 背景

当前工具栏中的刷新按钮会在加载时切换为停止按钮，但用户仍难以同时判断多个标签的加载状态。标签栏下方的全局进度条只能反馈当前标签，还会占用标签栏和工具栏之间的布局。本 Feature 将加载反馈移动到每个标签的网站标题前，并让 favicon 与加载环共用一个固定图标区域。

## 2. 功能需求

| ID | 需求 | 验收标准 |
|----|------|----------|
| F03-01 | 在加载标签内显示旋转图标 | 任一网站标签开始导航后，其标题前出现持续旋转的 loading 环；选中和后台加载标签均独立显示 |
| F03-02 | 在加载环内显示网站图标 | favicon 已获取时在加载环中心以 12 px 显示；尚未识别或网站没有 favicon 时，环内显示 12 px 默认网站图标 |
| F03-03 | 完成后恢复网站图标 | 成功、失败或用户停止导航后，该标签的加载环消失；真实 favicon 或默认网站图标恢复为 16 px |
| F03-04 | 保持标签布局稳定 | 加载状态和普通 favicon 共用固定 16 px 图标区域，状态切换不推动标题或改变标签高度 |
| F03-05 | 移除旧进度条 | 标签栏与工具栏之间不再渲染 2 px 水平加载进度条，也不保留对应布局间隙 |
| F03-06 | 提供默认 favicon | 网站没有 favicon、favicon 尚未识别或获取失败时显示组件库 Globe 默认网站图标，不让标题前出现无图标状态 |

## 3. 体验与兼容要求

- 使用当前主题的前景色或进度强调色，在亮色和暗色模式下均保持可见。
- 动效应克制，只旋转外层 loading 环，不旋转环内 favicon。
- 复用现有页面加载状态，不增加网络请求、不改变导航成功、失败或停止语义。
- 后台页面完成加载只更新自身标签，不影响其他标签的 loading 图标。

## 4. 非目标

- 不实现基于响应字节、子资源数量或渲染阶段的精确百分比。
- 不保留标签栏下方的全局进度条。
- 不持久化进度，不为已经完成或恢复的页面重放动效。
- 不在本 Feature 中修改工具栏刷新/停止按钮行为。

## 5. 验收证据

- 纯逻辑测试覆盖默认图标、真实 favicon 和加载三种标签图标模式。
- 既有导航生命周期确保开始时加入加载集合，成功、失败和停止时移除。
- UI 代码不再包含旧的 `selected-page-loading-progress` 元素。
- `arch-browser` 测试、严格 Clippy 和文档链接检查通过。
