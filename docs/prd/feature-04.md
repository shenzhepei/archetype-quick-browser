## 1. 背景

标签标题长度变化会改变标签宽度，例如在 `Settings - Language` 与 `Settings - About Archetype` 间切换时产生横向抖动。标签也缺少桌面浏览器常用的右键管理命令。

## 2. 需求与验收

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| F04-01 | 稳定宽度 | 标签数量和窗口宽度不变时，标题、favicon、加载状态变化均不改变标签宽度 |
| F04-02 | 少标签布局 | 标签较少时单个标签不超过 `220px`，新建标签按钮紧跟最后一个标签 |
| F04-03 | 多标签布局 | 标签增多时所有标签等宽收缩；达到 `116px` 最小宽度后标签区域可横向滚动 |
| F04-04 | 原生菜单 | 右键任意标签显示不被网页覆盖的 Electron 原生上下文菜单 |
| F04-05 | 菜单命令 | 提供重新加载、关闭、关闭其他标签页、关闭右侧标签页 |
| F04-06 | 目标标签 | 所有命令作用于被右键的标签；关闭当前活动标签时选择合理的相邻标签 |
| F04-07 | 可用状态 | 仅一个标签时禁用关闭其他标签页；右侧无标签时禁用关闭右侧标签页 |
| F04-08 | 国际化与安全 | 菜单提供英文和简体中文；Renderer 只传标签 ID 与坐标，主进程验证标签存在且不接受任意菜单模板 |

## 3. 非目标

- 不在本 Feature 中实现固定标签、标签分组或静音网站。
- 不改变标签顺序或增加拖拽排序。
