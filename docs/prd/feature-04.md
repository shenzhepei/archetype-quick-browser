# Feature 04 浏览器内部页与历史记录 PRD

| 字段 | 内容 |
|------|------|
| Feature ID | `feature-04` |
| 状态 | 已完成 |
| 来源 | 优先继续 HTML/CSS 能力与浏览器功能；从头像右侧三点菜单进入历史和设置，并采用 `archetype://` 内部协议 |
| 对应详设 | [feature-04.md](../detailed-design/feature-04.md) |

## 1. 背景

当前标签只持久化最后一次 URL 和标题，普通访问记录没有独立存储或可视页面。用户无法找回已经关闭或离开的页面，也无法查看和清理本地浏览记录。外观设置仍挤在头像弹出菜单中，也没有关于页面。本 Feature 建立受信任的 `archetype://` 内部页面路由，交付历史与设置的第一个完整闭环。

## 2. 功能需求

| ID | 需求 | 验收标准 |
|----|------|----------|
| F04-01 | 提供浏览器主菜单入口 | 在工具栏用户头像右侧显示三点图标按钮；点击后打开菜单，菜单包含“历史记录”项 |
| F04-02 | 使用内部历史页 | 点击“历史记录”打开或切换到唯一的 `archetype://history` 标签，不向网络 Loader 发起请求 |
| F04-03 | 持久记录成功访问 | 每次成功提交的顶层页面导航把最终 URL、最终标题和访问时间写入 profile SQLite；失败、停止、过期结果及内部页不写入 |
| F04-04 | 展示和筛选历史 | 历史页按访问时间倒序显示最近记录，并可按标题或 URL 即时筛选；无记录和无匹配结果有明确空状态 |
| F04-05 | 从历史重新打开页面 | 点击历史记录新建并选中普通标签导航到目标 URL，并继续经过正常网络、Cookie、安全和渲染管线；历史标签保留 |
| F04-06 | 管理本地历史 | 用户可以删除单条记录或清空全部历史；删除结果立即反映到页面并持久化 |
| F04-07 | 保持内部页浏览器语义 | 历史标签显示本地化标题，不允许收藏或重新加载内部页；重启恢复该标签时仍直接显示历史页 |
| F04-08 | 主菜单提供设置入口 | 三点菜单同时包含“历史记录”和“设置”；点击设置打开或切换到唯一设置标签 |
| F04-09 | 使用自有设置协议 | 设置入口打开 `archetype://settings/appearance`，切换设置分区时 URL 更新为对应的 `archetype://settings/*` 路由，不使用 `file://` 或网络请求 |
| F04-10 | 设置页具有左侧导航 | 设置页左侧固定显示“外观”和“关于 Archetype”，当前分区具有明确选中状态 |
| F04-11 | 迁移外观设置 | `archetype://settings/appearance` 显示“跟随系统、浅色、深色”三个单选项，选择后立即应用并继续写入现有 profile 偏好 |
| F04-12 | 提供关于页面 | `archetype://settings/about` 显示产品名 Archetype 和当前编译版本号 |
| F04-13 | 保留头像快捷入口 | 用户头像不再弹出外观菜单，点击后直接打开设置的外观分区；完整浏览器功能统一从三点主菜单进入 |

## 3. 数据与隐私要求

- 历史记录仅保存在当前本地 profile，不上传、不写入日志正文。
- 删除和清空必须直接更新 SQLite，不只隐藏 UI 数据。
- 历史记录在关闭来源标签后继续保留，不能用 `pages` 表外键级联删除。
- 首版页面最多读取最近 1000 条，避免无界构建 UI；数据库保留全部记录直到用户清理。
- `about:blank`、`archetype://history` 和未来 `archetype://` 内部页面不进入访问历史。

## 4. 兼容与本地化

- 菜单、标题、筛选框、空状态、删除和清空命令提供英文与简体中文文案。
- 历史页使用 GPUI 原生组件并跟随现有亮暗主题，不依赖网页 CSS 支持程度。
- `archetype://` 是 Browser 进程白名单内部路由，普通 Loader、Renderer 和网站内容无权注册或读取内部页面。
- 当前网页引擎没有 JavaScript/DOM 事件桥，历史和设置先使用受信任原生视图；未来可以替换为隔离的 bundled HTML WebUI，但不得改变内部 URL 和权限边界。
- 本 Feature 不改变网页 HTML/CSS 支持矩阵；网页能力继续按后续版本独立扩展。

## 5. 非目标

- 不在本 Feature 中实现跨设备同步、隐私模式、最近关闭标签或完整会话时间线。
- 不实现可执行内部 JavaScript、通用 `archetype://` 文件映射或网站可访问的内部资源目录。
- 不实现按日期范围批量删除、站点分组、无限滚动或导出。
- 不记录子资源请求、favicon 请求、失败导航和表单字段内容。
- 不将内部历史页暴露给 Renderer Runtime 或网站脚本。

## 6. 验收证据

- Store 测试覆盖事务写入、倒序读取、筛选所需字段、删除单条和清空。
- BrowserCore 测试覆盖成功导航写入、失败/陈旧结果不写入。
- UI 纯逻辑测试覆盖内部页识别和历史筛选。
- 严格 Clippy、`arch-store`/`arch-browser` 测试、工作区回归与文档链接检查通过。
