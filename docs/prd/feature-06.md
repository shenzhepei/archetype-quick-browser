## 1. 背景

设置页左侧菜单和语言切换控件可以点击，但悬停时仍显示默认箭头，缺少可交互反馈。

## 2. 需求与验收

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| F06-01 | 指针反馈 | 鼠标悬停设置页左侧菜单项时显示手型指针 |
| F06-02 | 语言切换反馈 | 鼠标悬停语言切换的英文、简体中文选项时显示手型指针 |
| F06-03 | 范围控制 | 指针样式只作用于设置侧栏菜单和分段切换按钮，不改变其他按钮状态 |
