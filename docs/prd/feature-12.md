## 1. 背景

标签页和书签数量增加后，当前横向滚动区域会显示系统箭头，且没有明确的书签溢出入口。书签栏也缺少就地管理命令。

## 2. 需求与验收

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| F12-01 | 书签栏右键菜单 | 在书签栏空白区域或书签项上右键，显示原生菜单 |
| F12-02 | 添加当前网页 | 右键菜单可收藏当前 HTTP/HTTPS/file 页面；已收藏或不可收藏时命令禁用 |
| F12-03 | 添加文件夹 | 右键菜单可打开唯一书签管理器并直接进入根目录新建文件夹表单 |
| F12-04 | 打开管理器 | 右键菜单可打开或定位到唯一书签管理器标签页 |
| F12-05 | 标签动态收窄 | 标签随可用宽度等宽收窄；紧凑标签默认显示 favicon，活动标签及悬停标签用关闭按钮替换 favicon，新增标签按钮仍位于标签组右侧 |
| F12-06 | 移除标签滚动箭头 | 标签栏不显示系统横向滚动条或左右箭头 |
| F12-07 | 书签溢出按钮 | 书签不能全部显示时，右侧显示双向右箭头“更多”按钮；无溢出时隐藏 |
| F12-08 | 查看溢出书签 | 点击“更多”显示仅包含溢出书签的原生菜单，保留 favicon 并可在当前标签打开 |
| F12-09 | 响应式更新 | 窗口尺寸、书签标题或书签数量变化后重新计算可见书签，不出现半截书签项 |
| F12-10 | 国际化与安全 | 新增菜单和无障碍名称完整支持英文、简体中文；主进程只接受固定命令和书签 ID |

## 3. 非目标

- 不实现标签页分组、垂直标签页或标签页搜索。
- 不在右键菜单中实现书签标题和 URL 编辑弹窗。
- 不实现书签栏拖拽排序。
