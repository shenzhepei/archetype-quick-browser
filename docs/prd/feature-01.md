## 1. 背景

V3-V7 版本文档描述浏览器引擎、Runtime、SDK 和 CSS 能力，但没有单独保存版本实施期间追加的浏览器外壳体验要求。本 Feature 固化地址栏、标签页、外观设置、favicon、站点访问和开发环境密钥行为，作为跨版本补充需求，不改变版本规范编号。

## 2. 用户目标

- 地址栏只保留高频动作，不显示与回车提交重复的控件。
- 标签页的新增、识别和切换方式符合桌面浏览器习惯。
- 用户可以明确选择系统、亮色或暗色外观，而不是依赖隐式逻辑。
- 普通开发启动不应反复触发 macOS 钥匙串授权。
- 静态、安全边界内的网站应尽可能加载正文、图片和站点图标。

## 3. 功能需求

| ID | 需求 | 验收标准 |
|----|------|----------|
| F01-01 | 删除网址输入框最右侧的清空按钮，改为收藏当前页面 | 地址栏右侧显示收藏按钮；点击后可收藏到根目录或已有文件夹 |
| F01-02 | 新建标签按钮紧跟现有标签 | `+` 位于最后一个标签右侧并随标签列表横向滚动，不固定在窗口最右端 |
| F01-03 | 提供外观设置 | 用户可选择“跟随系统、亮色、暗色”；选择持久化，系统模式响应系统外观变化 |
| F01-04 | 删除地址栏右侧“前往”箭头，改为用户入口 | 回车仍是地址提交方式；用户头像按钮打开包含外观选项的设置菜单 |
| F01-05 | 标签显示网站 favicon | 优先读取文档 `link[rel~=icon]`，否则尝试站点 `/favicon.ico`；成功后在对应标签显示 |
| F01-06 | 恢复百度等 HTTPS 网站的基础加载 | 文档通过 Browser broker 加载并进入 Runtime；失败必须显示可诊断原因，不静默空白 |
| F01-07 | `cargo run -p arch-browser` 不访问钥匙串 | Debug 构建使用 profile 同目录私有密钥文件；Release macOS 构建继续使用 Keychain |

## 4. 交互规则

- 地址提交只有回车一种主路径，避免同时出现“前往”按钮。
- 收藏和用户设置是地址栏右侧的两个独立动作。
- 外观默认值为“跟随系统”，不是按时间自动切换。
- favicon 加载失败不阻止正文渲染，标签退化为纯文本。
- Debug 密钥文件权限在 Unix 平台必须为 `0600`，不得明文持久化 Cookie。

## 5. 非目标

- 不在本 Feature 中实现账号登录、云同步或头像资料。
- 不取消 V4 对静态子资源的同源、大小、重定向和 Cookie 策略。
- 不承诺 JavaScript、完整 CSS、CORS 或 CSP 的浏览器规范等价实现。
- Release 构建不绕过 macOS Keychain。

## 6. 验收与追踪

- UI：收藏按钮、用户设置入口、外观三选项和随标签滚动的新增按钮可操作。
- 状态：外观选择、收藏、标签选择和 Cookie 加密状态可恢复。
- 网络：站点加载错误分类明确，favicon 失败与页面加载解耦。
- 安全：Debug 密钥权限测试通过，Release Keychain 路径保持条件编译隔离。
- 后续兼容性修复见 [feature-02](./feature-02.md)。
