## 1. 产品目标

提供可侧载、可审计的零信任扩展能力。扩展向浏览器声明意图和规则，由浏览器原生执行；扩展代码默认不能进入网页上下文，也不能常驻读取用户数据。

## 2. 用户价值

- 用户可获得拦截、隐藏、主题和 Space 模板等常用定制能力。
- 安装时能够理解扩展将执行的规则类型，而非接受笼统的全站权限。
- 敏感数据仅在明确的用户手势和有时限的授权下开放。
- 扩展包可校验来源与内容，便于侧载和社区审计。

## 3. 范围与优先级

### 3.1 P0：声明式能力

- 网络规则：阻止、HTTPS 升级、有限重定向。
- 元素隐藏：仅使用经引擎校验的选择器。
- 新标签页、地址栏关键词、主题和 Space 模板。
- `.archx` 包或目录侧载、内容哈希和签名校验。
- 原生规则引擎编译、原子更新和失败回滚。

### 3.2 P1：隔离 UI 与规则生态

- popup/options 运行于独立扩展源，不提供页面 DOM bridge。
- 扩展私有的限额本地存储。
- 无网络、无磁盘权限的纯计算 WASM。
- EasyList 类规则向内部支持子集转换。
- 精选扩展列表及构建说明。

### 3.3 P2：会话级敏感能力

- `activeTab.url`、`activeSpace.read` 等能力默认关闭。
- 仅提供“本次”或“30 分钟”授权，过期立即撤销。
- Space 切换时不默认继承敏感权限。

## 4. 权限与安全要求

| 场景 | 产品要求 |
|------|----------|
| 安装 | 展示声明式规则类型和影响范围 |
| 敏感 API 调用 | 由用户选择仅本次、30 分钟或拒绝 |
| 页面后台化或休眠 | 不唤醒扩展 |
| 扩展更新 | 校验签名和内容哈希，失败保留上一版本 |
| Chromium 兼容舱 | 强制禁用全部扩展 |

## 5. 非目标

- 不兼容 Chrome/Edge MV3 的 `chrome.*` API。
- 不支持 Content Script 任意读写页面 DOM。
- 不提供 `<all_urls>` 常驻访问、全历史嗅探或默认 nativeMessaging。
- 不允许扩展包动态加载远程可执行代码。
- 首年不建设封闭应用商店。

## 6. 验收标准

- 用户能侧载签名 `.archx` 包，并在安装前看到规则能力摘要。
- 网络阻止和元素隐藏规则由原生引擎执行，网页上下文中不存在扩展脚本。
- 恶意清单、危险选择器和超大规则集会被拒绝或明确降级。
- 敏感权限到期后相关 API 立即失败，且不跨 Space 默认继承。
- 扩展更新可原子替换规则，校验或编译失败时自动回滚。
- Chromium 兼容舱无法加载任何 Archetype 扩展。

## 7. 里程碑

| 版本 | 交付 |
|------|------|
| M1 | Tier 0 网络/隐藏规则与 `.archx` 侧载 |
| M2 | 隔离 popup/options 和私有存储 |
| M3 | EasyList 支持子集导入 |
| M4 | 会话级敏感权限与精选列表 |
