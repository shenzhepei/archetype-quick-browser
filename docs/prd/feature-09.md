## 1. 背景

浏览器已经提供网页保存和常用主菜单命令，但缺少调用系统打印流程的入口。

## 2. 需求与验收

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| F09-01 | 网页右键打印 | 网页右键菜单在“网页另存为”下方显示“打印” |
| F09-02 | 主菜单打印 | 右上角三点菜单在“历史记录”下方显示“打印” |
| F09-03 | 目标网页 | 两个入口均打印所属窗口当前或右键触发的网页，不打印其他标签 |
| F09-04 | 原生流程 | 使用 Chromium/Electron 原生打印对话框并包含网页背景 |
| F09-05 | 可用状态 | 空白页和 Archetype 内部页不打印浏览器外壳，主菜单打印项保持禁用 |
| F09-06 | 国际化 | 打印命令和失败提示支持英文与简体中文 |
| F09-07 | 取消与失败 | 用户取消打印不显示错误；没有系统打印机或 Chromium 打印失败时显示受控提示 |

## 3. 非目标

- 不实现静默打印、默认打印机选择或打印偏好持久化。
- 不在本 Feature 中提供直接导出 PDF 的独立命令。
