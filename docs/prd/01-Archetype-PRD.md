## 1. 一句话与定位

> **浏览器不是操作系统，而是你思想的过滤器。**

Archetype 是一款以 **本地优先 · 专注工作流 · 隐私原生** 为支柱的桌面浏览器。

不与 Chrome/Safari 拼「全能兼容」，而拼：

| 支柱 | 相对 Chrome | 相对 Safari | Archetype |
|------|-------------|-------------|-----------|
| 本地优先 | 无 Google 账号/云 AI 默认 | 不绑 Apple ID 唯一路径 | 数据默认落盘；云与 AI 皆 opt-in |
| 专注工作流 | 标签海 + 推荐噪音 | 仍是通用浏览壳 | Space 项目制 + 默认专注 + 阅读模式 |
| 隐私原生 | 扩展与站点权限过宽 | 强但闭源/绑系统 | 零信任扩展 + 一次性授权 + E2E 自选同步 |
| 资源模型 | 进程易膨胀 | 更省但不可控 | 前台 / 后台快照 / 磁盘休眠 三级 |

---

## 2. 目标用户与场景

- 需要长时间多主题并行（论文、采购、本周工作）且讨厌标签失控的人  
- 在意隐私、不愿厂商账号同步与默认云 AI 的人  
- 可接受「公开支持矩阵」、不要求打开任意网站的早期采用者  
- 内网 / 专用工作流（阅读、项目资料）可裁剪部署的场景  

---

## 3. 产品原则

1. **过滤器，不是 OS**：默认无新闻、天气、推荐；地址栏极简。  
2. **本地优先**：核心数据与推理默认不上云。  
3. **内存有预算**：休眠与停 JS 是一等能力，不是插件。  
4. **扩展不可住进网页**：扩展提交规则，浏览器原生执行。  
5. **兼容不污染主环境**：Chrome-only 仅可选隔离舱，用完即焚。  
6. **诚实降调**：内存 30–40%、瞬间唤醒、内置大模型等不作首发硬保证。

## 4. 功能需求

### 4.1 Space 工作流（P0）

- 左侧 Space 列表；Space 内垂直页面列表（嵌套、备注、待办）  
- 关闭 Space → 页面全部休眠，上下文可完整恢复  
- 默认专注模式；深度阅读模式（本地抽正文，不上云）  
- 番茄钟与站点统计仅本地存储  

### 4.2 三级资源模型（P0）

| 层级 | 行为 | JS |
|------|------|-----|
| Foreground | 完整渲染与交互 | 运行 |
| Background | 保留 DOM/滚动/表单等快照 | **冻结** |
| Hibernated | 序列化落盘，内存接近 0 | 无 |

- KPI：**目标**同等标签数下内存约为 Chrome 的 30–40%（需基准剧本测量，首发公布实值）  
- 唤醒：交互可点目标 &lt; 300ms；JS 热起来可更长并显示进度  

### 4.3 浏览与引擎（P0→P1）

- 主路径：**全自研**渲染管线（非 Blink/Gecko/Servo 嵌入）  
- 公开 **兼容性/支持矩阵**，不宣称替代 Chrome  
- 可选 **Chromium 兼容舱**：无扩展、无持久 Cookie/历史，用完即焚  

### 4.4 安全与权限（P0）

- 地理/通知/相机/麦克风等：**默认拒绝**  
- 授权形态：仅本次 / 30 分钟后自动撤销  

### 4.5 零信任扩展（P1）

- 自有清单与能力模型（非 Chrome MV3 兼容承诺）  
- Tier0：声明式网络屏蔽与元素隐藏；侧载签名包  
- 可导入 EasyList 类规则子集；规则由原生引擎执行  
- 独立需求见：[02 扩展系统 PRD](./02-Archetype-扩展系统-PRD.md)  
- 详见详设：[扩展系统详设](../detailed-design/02-Archetype-扩展系统详设.md)  

### 4.6 同步（P1）

- 无厂商账号  
- 书签/历史/密码/Space 上下文 E2E 加密后，同步到用户自选槽（文件夹 / WebDAV / NAS 等）  
- 后期：局域网 P2P  

### 4.7 本地 AI（P2，可选）

- 默认不捆绑大模型权重  
- 可选下载端侧模型：摘要、Space 分类、本地表单记忆  
- 云端 AI 仅插件，默认关  

---

## 5. 非目标（首发不做）

- 完整 Chrome/Edge MV3 扩展兼容（`chrome.*` / Content Script DOM 注入）  
- 主路径嵌入 Blink/Gecko/Servo/系统 WebView  
- 厂商账号云同步、默认捆绑 4–7B 模型  
- 宣称全面替代 Chrome/Safari、完整 ES/Service Worker/DRM 等  

---

## 6. 竞品对照（决策用）

| | Chrome | Safari | Archetype |
|--|--------|--------|-----------|
| 核心优势 | 兼容与生态 | 能效与系统一体 | Space + 休眠 + 隐私默认 + 自研可控 |
| 扩展 | MV3，可注入 DOM | 更瘦，App Store | 声明式零信任 |
| 同步 | Google 账号 | Apple 账号 | 用户自选 E2E |
| 引擎 | Blink | WebKit | 全自研 + 可选 Chromium 舱 |

学 Chrome：隔离与 IPC 纪律。学 Safari：能效与克制。不抄二者的「全能浏览器」包袱。

---

## 7. 商用与许可（产品约束）

- 全自研主路径：**可以商业牟利**；引擎 IP 自有 + 宽松依赖  
- 不依赖 Servo/Gecko 作为产品链接（避免整引擎 MPL 义务；解析库若用 MPL crate 则按文件级合规）  
- 禁止默认使用 GPL 路径 UI（如未付费的 Slint-GPL）  
- 商标：不得冒充 Firefox/Chrome  

---

## 8. 里程碑与验收（产品视角）

| 版本 | 大约周期 | 验收要点 |
|------|----------|----------|
| V3 | 3–6 月 | 金样静态页可读（布局/图/链/滚） |
| V4 | 6–12 月 | Space + 三级休眠 + 阅读模式 + Cookie/表单；支持矩阵公开 |
| V5 | 12–24 月 | 轻量 JS + 声明式扩展 Tier0/1 + E2E 同步 |
| V6 | 并行/之后 | 可选 Chromium 舱；可选本地 AI |

详细工程阶段见详设总体文档；第一个可实施版本以 [03 Archetype V3 PRD](./03-Archetype-V3-PRD.md) 为范围基线。

---

## 9. 成功标准

- 用户能用 Space 管理多主题而不靠「几十个标签」  
- 后台页默认不跑 JS；休眠后内存可测下降  
- 扩展无法在未授权下读取浏览历史或注入任意 DOM  
- 核心路径无厂商账号、无默认上云  
- 法务可讲清：主引擎自有，第三方 NOTICE 完整
