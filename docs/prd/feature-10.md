## 1. 背景

Archetype 已支持地址栏星标、书签栏和完整历史页，但主菜单仍以单层命令打开历史记录，且没有书签菜单和集中管理页面。

## 2. 需求与验收

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| F10-01 | 历史二级菜单 | 主菜单“历史记录”改为二级菜单，包含完整历史记录入口和最近访问项 |
| F10-02 | 最近历史 | 最多显示最近 8 条，展示标题并提供 URL 提示；无记录时显示禁用空状态 |
| F10-03 | 书签二级菜单 | 主菜单新增“书签”二级菜单，包含收藏/取消当前页、完整书签入口和最近书签 |
| F10-04 | 最近书签 | 最多显示最近添加的 8 条书签；点击历史或书签最近项时在新标签打开 |
| F10-05 | 书签管理页 | `archetype://bookmarks` 展示全部书签，支持打开和移除 |
| F10-06 | 唯一工具页 | 重复打开完整历史或书签管理时定位既有标签，不创建重复工具页 |
| F10-07 | 安全边界 | 主菜单内容完全来自当前窗口状态，Renderer 不能提交任意历史、书签或菜单模板 |
| F10-08 | 国际化 | 主菜单、空状态和书签管理页支持英文与简体中文 |
| F10-09 | 书签 favicon | 书签栏、书签二级菜单和书签管理页显示网站 favicon；缺失或加载失败时显示默认网站图标 |
| F10-10 | 图标持久化 | 新增书签缓存受限大小的 favicon，重启后无需等待网页重新访问即可显示 |

## 3. 非目标

- 不在本 Feature 中实现书签文件夹、拖拽排序、导入导出或跨设备同步。
- 不实现最近关闭标签页和其他设备标签页。
- 不改变现有地址栏星标和书签栏行为。
