## 1. 背景

Browser Chrome 与普通网页分别运行在独立 `WebContentsView`。React 菜单伸出工具栏后进入网页视图区域，会被后加入的网页视图覆盖，CSS `z-index` 无法跨原生视图层级解决。

## 2. 需求与验收

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| F02-01 | 菜单层级 | 打开任意普通网站后点击三点按钮，菜单完整显示在网页之上 |
| F02-02 | 菜单命令 | 历史记录、设置入口继续打开对应 Archetype 内部页 |
| F02-03 | 语言设置 | 三点菜单不单列语言项；设置左栏提供语言页面，English 与简体中文切换后立即生效并持久化 |
| F02-04 | 平台一致性 | macOS、Windows 和 Linux 使用各自系统原生菜单交互与阴影，不受网站 CSS 影响 |
| F02-05 | 安全边界 | Renderer 只能请求显示固定命令菜单，不能向主进程传入任意菜单模板或可执行命令 |
| F02-06 | 工具标签 | 从头像或三点菜单进入设置时不覆盖当前网页；没有设置标签则新建，已有任意设置标签则直接定位 |
| F02-07 | 历史标签 | 从三点菜单进入历史时不覆盖当前网页；没有历史标签则新建，已有则直接定位 |
| F02-08 | 语言布局稳定 | English 与简体中文切换前后，Browser Chrome 和设置页控件行高不变，不发生纵向抖动 |
| F02-09 | 设置标签标题 | 栏目切换后标题显示“设置 - 外观/语言/关于 Archetype”或对应英文，语言切换后立即同步 |
| F02-10 | 菜单规格 | 三点菜单具有更宽的稳定宽度，历史记录和设置项左侧显示语义图标 |
| F02-11 | 设置图标一致性 | 设置左侧栏目与对应内容标题使用相同语义图标，外观栏目统一使用 Palette 图标 |

## 3. 非目标

- 不在本 Feature 中实现网站右键菜单。
- 不提供可由网站扩展的 Browser Chrome 菜单项。
