## 1. 背景

右上角主菜单目前只有历史记录和设置，缺少新建标签页、新建窗口和 Chromium 扩展程序管理入口。

## 2. 需求与验收

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| F08-01 | 打开新的标签页 | 主菜单提供“打开新的标签页”，在触发菜单的窗口中创建并选中空白标签 |
| F08-02 | 打开新的窗口 | 主菜单提供“打开新的窗口”，创建独立 Archetype 窗口和空白标签，不替换原窗口 |
| F08-03 | 窗口隔离 | 每个窗口的地址栏、标签和菜单命令只操作自身 Controller |
| F08-04 | 扩展菜单 | 主菜单提供“扩展程序”子菜单，子菜单包含“管理扩展程序” |
| F08-05 | 管理页面 | 管理入口打开或定位唯一的 `archetype://extensions` 标签，展示已加载扩展 |
| F08-06 | 加载扩展 | 管理页可通过系统目录选择器加载 Chromium 已解压扩展 |
| F08-07 | 移除扩展 | 管理页可卸载指定扩展，并立即刷新列表 |
| F08-08 | 启动恢复 | 成功加载的扩展目录持久化，后续启动尝试恢复；失效目录不会阻塞浏览器启动 |
| F08-09 | 国际化与安全 | 菜单、管理页和错误提示支持英文与简体中文；Renderer 不能提交任意扩展路径 |

## 3. 非目标

- 不支持 Chrome Web Store 直接安装或 `.crx` 安装。
- 不实现 Electron 尚未支持的 Chrome Extension API。
- 不在本 Feature 中实现扩展启用/停用切换、权限详情或自动更新。
- 新窗口标签不参与主窗口的启动恢复集合。
