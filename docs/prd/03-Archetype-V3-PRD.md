## 1. 版本目标

V3 用一个可运行的垂直切片验证 Archetype 的核心技术路线：用户可以在 Space 中打开受支持的本地或 HTTP(S) 静态页面，完成解析、布局、绘制、滚动和链接导航，并可在重启后恢复 Space 与页面列表。

V3 是开发者预览版，不作为通用浏览器发布，也不承诺打开任意网站。

## 2. 目标用户与使用场景

- 核心开发团队使用固定金样页面验证自研渲染管线。
- 内部体验者浏览项目文档、文章和其他无 JavaScript 的静态内容。
- 产品团队验证 Space 导航是否比传统标签页更适合多主题整理。

## 3. V3 必须交付

### 3.1 应用外壳与 Space

- 创建、重命名、切换和删除 Space。
- 每个 Space 包含扁平页面列表；支持新增、选择、关闭页面。
- 提供地址输入、后退、前进、重新加载和停止加载。
- 重启后恢复 Space、页面 URL、标题、顺序和最后选中页面。

### 3.2 静态浏览

- 打开 `file://` 金样和 HTTP(S) 页面。
- 支持 HTML 基础结构、CSS 基础级联、块/行内布局、文本、PNG/JPEG、链接和纵向滚动。
- 支持 UTF-8 和中英文系统字体 fallback。
- 页面不执行 JavaScript；遇到脚本时忽略并在开发诊断中记录。
- 对不支持的 HTML/CSS 能力稳定降级，不能导致应用崩溃。

### 3.3 本地存储与诊断

- 使用 SQLite 保存 Space 和页面元数据。
- 提供结构化本地日志，不采集、不上传遥测。
- 保存金样截图并执行像素或感知差异回归。
- 展示加载失败、证书失败和不支持页面的明确错误状态。

## 4. V3 验收标准

| 维度 | 验收标准 |
|------|----------|
| 启动 | Apple Silicon 测试机上冷启动至可操作界面 P95 小于 2 秒 |
| 稳定性 | 规定的 30 个金样页面连续运行 2 小时，无崩溃 |
| 渲染 | 30 个金样全部可读；关键金样截图差异低于详设规定阈值 |
| 导航 | 金样内链接、后退、前进、重新加载全部通过自动化测试 |
| 持久化 | 强制退出并重启后，Space 和页面列表 100% 恢复 |
| 错误处理 | 无效 URL、断网、超时、证书错误均显示可恢复错误页 |
| 质量 | 核心解析、布局、存储模块有单元测试；金样回归进入 CI |

内存与唤醒 KPI 在 V3 只建立测量基线，不验收“Chrome 的 30–40%”或“小于 300ms”。

## 5. 明确不进入 V3

- JavaScript、DOM API、表单提交、音视频、下载和打印。
- Flexbox、Grid、定位、动画及完整响应式布局。
- 完整三级资源模型；V3 仅恢复页面元数据并重新加载 URL。
- 多进程 Renderer、操作系统沙箱和 GPU 独立进程。
- Cookie、登录会话、密码管理、站点权限。
- 阅读模式、番茄钟、站点统计。
- 扩展系统、同步、Chromium 兼容舱和本地 AI。
- Windows、Linux、Intel Mac、移动平台。
- 面向公众分发、自动更新和代码签名发布流程。

## 6. 下一版本 TODO

V4 优先补齐可日常试用的安全与会话能力：

1. Renderer 多进程与 macOS 沙箱。
2. Cookie、基础表单、会话历史和站点权限。
3. Background/Hibernated 快照格式、加密和迁移。
4. 基础 Flexbox、更多 CSS 属性和公开支持矩阵。
5. 阅读模式和完整 Space 层级、备注、待办。
6. 性能基准固定化，并开始执行内存和恢复时延目标。

扩展、E2E 同步、Chromium Pod 与 AI 继续按总体路线图进入 V5 或更后版本。

## 7. 发布条件

只有在全部 V3 验收项通过、已知问题有记录、依赖许可证清单完整时，才能标记 V3 完成。任何新增能力必须先替换同等工作量或进入后续版本，不得无条件扩大 V3 范围。
